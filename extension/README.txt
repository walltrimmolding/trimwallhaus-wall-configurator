TRIM WALL HAUS WALL CONFIGURATOR — CHROME EXTENSION

Local test install:
1. Open chrome://extensions
2. Turn on Developer mode
3. Choose Load unpacked
4. Select this extension folder
5. Click the Trim Wall Haus extension icon

Included in version 1.2.0:
- 5 wall-molding layout calculators with cut lists
- Stair riser and run calculator
- Room paint calculator
- Wall square-footage calculator
- Wallpaper roll calculator
- Baseboard calculator

Open "Stair, Paint & Project Tools" from the header to switch to the utility calculators.

The configurator opens in a full browser tab. Live price requests are read from
trimwallhaus.com. The free drawing form posts to the store's Shopify contact form.
